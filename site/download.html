Download

Zycord 2.0.0 for Windows 10 and Windows 11, 64-bit

One executable, no background service and no administrator rights. Run it, choose Install, and the launcher is ready; updates and uninstalling are buttons inside it.

Get the release

The download is the executable itself. Everything Zycord needs — the launcher, the session stub, the interface, the catalog and the WebView2 assemblies — is inside that one file, so there is nothing to unpack and nothing else to install. A zip is published beside it for anyone who wants one.

All releases

The executable is 1.14 MB on its own, and about 3.1 MB once installed. Each prepared game adds about 36 KB.

Verify the download

Every release publishes the SHA-256 of both downloads in SHA256.txt on its GitHub release page. Compare the one you downloaded before you run anything. On Windows: 

certutil -hashfile Zycord-2.0.0.exe SHA256

On Linux or macOS, with the download and the published hash side by side:

sha256sum Zycord-2.0.0.exe

SHA256.txt lists the executable and the archive, one digest per line, so the same check works for either file.

What is inside the executable

The download is a single file. These are the parts it carries and unpacks into %LOCALAPPDATA%\Zycord\app when you choose Install: 

Zycord.exe                       the download, launcher and payload in one file
  Zycord.exe                     the launcher
  stub.exe                       the session process, about 36 KB
  ui/
    index.html                   the interface
    app.css
    app.js
    catalog.json                 10,468 games
    mark.svg
  Microsoft.Web.WebView2.Core.dll
  Microsoft.Web.WebView2.WinForms.dll
  WebView2Loader.dll
  README.md
  LICENSE

A zip is published beside it for anyone who wants the loose files, but it is not the download the button gives you.

Installing

  1. Run the downloaded Zycord-2.0.0.exe. There is nothing to unpack.
  2. Choose Install. It copies itself to %LOCALAPPDATA%\Zycord\app and adds a Start Menu shortcut.
  3. If Windows shows a SmartScreen warning, choose More info and then Run anyway.

There is no elevation prompt. The launcher runs as your user and writes only to %LOCALAPPDATA%\Zycord. Choosing No instead of Install runs it once without installing anything.

Upgrading and removing

Both happen inside the app, so you do not need the downloaded file again. When a new release is published, Zycord offers it: it downloads the archive, checks it against the published SHA-256, and restarts into the new version. Settings, logs and prepared game files live in %LOCALAPPDATA%\Zycord and are kept.

Uninstall on the Settings tab removes the program files, the Start Menu shortcut, the Add or remove programs entry and the data folder. Nothing outside %LOCALAPPDATA%\Zycord and the shortcut is written.

Why SmartScreen warns. The executable is not signed with a code-signing certificate. Signing certificates cost money and identify a legal entity, and this project does not have one, so Windows cannot verify the publisher. If that matters to you, build from source instead. The documentation explains how, and the build uses only the compiler that ships with Windows.
