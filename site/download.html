Download

Zycord 1.1.3 for Windows 10 and Windows 11, 64-bit

One zip archive, no installer, no background service and no registry entry. Extract it, run Zycord.exe, and the launcher is ready.

Get the release

The archive contains the launcher, the session stub, the interface, the catalog and the WebView2 assemblies. There is nothing else to install.

Download Zycord-1.1.3.zip All releases

The download is 0.95 MB. Unpacked, it is about 3.1 MB. Each prepared game adds about 36 KB.

Verify the download

Every release publishes the SHA-256 of the archive on its GitHub release page. Compare it before you run anything. On Windows: 

certutil -hashfile Zycord-1.1.3.zip SHA256

On Linux or macOS, with the archive and the published hash side by side:

sha256sum Zycord-1.1.3.zip

Installing

  1. Extract the archive to a folder you can write to, for example C:\Users\you\Apps\Zycord.
  2. Run Zycord.exe.
  3. If Windows shows a SmartScreen warning, choose More info and then Run anyway.

There is no installer and no elevation prompt. The launcher runs as your user and writes only to %LOCALAPPDATA%\Zycord.

Upgrading and removing

To upgrade, extract the new version over the old folder. Settings, logs and prepared game files live in %LOCALAPPDATA%\Zycord and are not touched.

To remove it, stop any running sessions, delete the folder you extracted, then delete %LOCALAPPDATA%\Zycord to remove settings, logs and prepared files.

Why SmartScreen warns. The executable is not signed with a code-signing certificate. Signing certificates cost money and identify a legal entity, and this project does not have one, so Windows cannot verify the publisher. If that matters to you, build from source instead. The documentation explains how, and the build uses only the compiler that ships with Windows.
