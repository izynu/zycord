Windows launcher for Discord quests

A game process Discord already recognises, started in one click.

Zycord copies a small stub executable into %LOCALAPPDATA%\Zycord\games\<app_id>\, renames it to the executable Discord watches for a game, and starts it. Discord credits PLAY_ON_DESKTOP quest progress while the stub runs. The stub has no game code, no network code and never contacts Discord.

What Zycord does

Five things, each with a clear boundary.

01

Searches the catalog

10,465 games with 11,171 executable entries, searchable by name, alias and theme. Filters narrow to single-executable, multi-executable, launcher or custom games, and any title you add yourself is searchable beside them.

02

Prepares a session file

Copies the about 35 KB stub into a per-game folder and gives it the filename Discord expects, including any subfolder the catalog records.

03

Starts and tracks it

Starts the process and records its process id. The Sessions tab shows a live timer, and an optional auto stop ends it for you.

04

Keeps a local history

Every session is recorded with its start, stop, duration and reason. Favourites and a saved library sit beside it in one settings file.

05

Cleans up

One action removes every prepared game folder. It refuses while a session is running, so nothing is deleted while in use.

Start a session in four steps

From opening the launcher to a running session takes a few seconds.

1

Open Games

The catalog loads with the application, so search works immediately. Type a name, pick a theme, or filter by executable count.

2

Choose the executable

Most games register one executable. Where a game registers several, each is listed and launcher processes are marked.

3

Start

Zycord prepares the file, starts the process and records its process id. A small window shows elapsed time unless you turn it off.

4

Stop when done

Stop from the Sessions tab, the session window or the tray menu. A typical PLAY_ON_DESKTOP quest needs about 15 minutes.

What it does not do

Deliberate omissions, not features waiting to be added.

  • No sign-in, token or stored credential.
  • No patch, injection or read of the Discord client.
  • No network request from the launcher except Discord CDN icons.
  • No telemetry, analytics, crash reporting or update check.
  • No installer, background service or scheduled task.

Read the safety page for the full boundary.

Before you use it

Discord has not documented or endorsed this use. Progress gained this way can be removed and accounts can be actioned. Zycord is built carefully, but it does not make the practice safe. Read the terms before you start a session.

Common questions

Do I need the game installed?

No. Zycord starts a copy of its own stub with the game's executable name. Your real game folder is never touched.

Is anything sent to Discord?

No. The launcher starts a local process. Discord's own client does the detection, and the stub makes no network call.

How long does a quest take?

A typical PLAY_ON_DESKTOP quest needs about 15 minutes of the game appearing to run. Leave the session running and Discord credits it.

Why does SmartScreen warn me?

The executable is not signed with a code-signing certificate. Choose More info and then Run anyway, or build from source.
