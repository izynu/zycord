Features

Everything in the launcher, and what each control actually does

Zycord 1.1.4 is one window with ten sections. Every feature below exists in this release; nothing here is planned or partial.

Catalog and search

A fixed catalog shipped with the application, searched locally.

Catalog

10,465 games

Generated from Discord's public detectable list at build time. 11,171 executable entries, 10,452 games with an icon.

Search

Name and alias

Type any part of a game name or one of its registered aliases. Matching is a case-insensitive substring check, so partial words work.

Filters

Theme and executable count

Filter by any theme in the catalog, then to games with a single executable, multiple executables, or a marked launcher process.

Sort

Three orders

Name A to Z, name Z to A, or most executables first. The catalog opens sorted by name.

Icons

Discord CDN, with fallback

Icons load from Discord's icon CDN. If one fails, a lettered tile is shown instead, so the grid never breaks.

Paging

120 at a time

Results render in pages of 120 with a load more action, which keeps a large result set responsive.

Sessions

One process per game, tracked by id from start to stop.

Start

One click

Pick a game and an executable, then start. Zycord prepares the file, starts the process and records its process id.

Timer

Live elapsed time

The Sessions tab and the session window both show elapsed time, updated while the session runs.

Auto stop

1 to 240 minutes

Set in steps of 15 minutes. Zero disables it. A running session can be extended by 15 minutes from the session list.

Stop

One or all

Stop a single session, or stop all with a confirmation step if you enabled it in Settings.

Multiple

Independent sessions

Run several games at once. Each session has its own file, process id and timer.

Lifetime

Tied to the launcher

Each stub watches the launcher that started it and exits if that launcher disappears, so a crash cannot leave an unstoppable session.

Library, favourites and history

Local records that survive restarts.

Library

Saved games

Saving a game records the game and the executable you chose. Start or remove it from the Library tab.

Favourites

A separate shortlist

Star any game to keep it in Favourites with its own count in the rail, independent of the library.

Recent

The last 12

Recently started games appear on Home for a quick return, capped at 12 entries.

History

Up to 250 sessions

Each entry records start, stop, duration and reason: stopped, exited on its own, or auto stopped.

Clearing

Separate controls

History and recents, the library and favourites, and settings each have their own clear action.

Persistence

One settings file

Library, favourites, recents, history, preferences and window bounds live in one JSON document.

Window, tray and appearance

A normal desktop application, with the options you would expect.

Tray

Minimise to tray

Closing the window can keep Zycord and its sessions running. Turn it off and closing the window stops every session.

Startup

Start minimised

Open straight into the tray when you want the launcher out of the way.

Always on top

Keep on top

Leave the launcher above other windows, useful while watching a timer.

Themes

Glass and light

The default graphite glass finish, or a light theme. The choice is stored with your settings.

Motion

Reduce motion

Turns off the background animation in the launcher.

Single instance

One window

Launching Zycord again brings the existing window forward instead of opening a second copy.

Storage and diagnostics

Everything the application writes, visible and removable.

Storage

Size readout

Settings shows prepared game file size and log size, with a button to open the data folder.

Cleanup

Clear game files

Removes every prepared folder. It refuses while a session is running, because a running process is using one of those files.

Logs

One file per day

Plain text with session starts and stops, process ids, refused operations and errors. A file rolls over at 4 MB.

Log tools

Refresh, copy, export, clear

Read today's log in the interface, copy it, export it to a file, or clear it.

Paths

Local app data

Settings, logs, prepared games and the WebView2 profile all sit under one folder you can delete at any time.

Settings safety

Atomic writes

A temporary file is written and moved over the original, and unreadable settings fall back to defaults.
