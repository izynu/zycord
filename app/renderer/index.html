About

            
Zycord

            
A Discord quest and presence companion for Windows.

          

        


        

          
          

            
Zycord v1.1.3

            
Quests and presence, without the guesswork. Zycord prepares a small stub under the executable name Discord expects, then keeps it running for as long as you need.

            

              
              
              
            

          

        


        

          

            
What it does

            
    
              
  • Credits desktop-play quests through Discord's normal process detection.
    • 
              
  • Shows a live timer and an auto stop for every session.
    • 
              
  • Keeps a library, favourites and a full session history.
    • 
              
  • Writes to its own app data folder, except a log export you choose the location for.
    • 
            

          

          

            
Safety

            
    
              
  • Paths are validated and re-checked before any file is written.
    • 
              
  • Sessions stop by process id, never by image name.
    • 
              
  • Closing Zycord stops every stub it started.
    • 
              
  • No account, no token and no gateway connection.
    •

Questions

            
Is anything sent to Discord?
No. Zycord only runs a local process with a particular file name. Discord's own client does the detecting.

            
Why does the session window appear?
It is a reminder that a stub is running. Turn it off in Settings to run hidden.

            
Do I need the game installed?
No. The stub is a copy of a small file Zycord ships. It never touches your real game folder.

            
Will a custom game show as activity?
Only if Discord already lists the file name you enter. The custom dialog checks it against the same list the catalog comes from and says what it finds before you add the game.

            
The quest still shows as not started
Give Discord a minute, then open the quest page. Some quests need the game to be the foreground window; Zycord's session window helps with that.

            
Where are my files?
Everything lives in your local app data folder under Zycord. Use the Data folder button on the About tab.

            
Can I run several games at once?
Yes. Each session is independent and appears on the Sessions tab.
